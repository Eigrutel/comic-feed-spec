# Schémas structurels Comic Feed 1.0

Deux schémas JSON Schema 2020-12 autonomes sont fournis. Les $ref sont internes. Le $id en .example est un identifiant documentaire, pas une adresse à charger. Les champs inconnus sont tolérés pour la compatibilité ; un producteur 1.0 place ses expérimentations dans extensions. Compléter ces schémas par les règles de SPECIFICATION.md, en particulier dates civiles, langues, unicité des IDs, accès hérité, relations, transitions et réseau.
